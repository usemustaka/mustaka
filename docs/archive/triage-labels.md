# Triage Labels

Skill berbicara dalam istilah lima role triage kanonik. File ini memetakan role ke string label yang sebenarnya digunakan di issue tracker repo ini.

| Label di mattpocock/skills | Label di tracker kami | Fungsi                                 |
| --------------------------- | --------------------- | -------------------------------------- |
| `needs-triage`              | `needs-triage`        | Maintainer perlu mengevaluasi issue    |
| `needs-info`                | `needs-info`          | Menunggu reporter untuk info lebih     |
| `ready-for-agent`           | `ready-for-agent`     | Fully specified, siap untuk agent      |
| `ready-for-human`           | `ready-for-human`     | Perlu implementasi manual              |
| `wontfix`                   | `wontfix`             | Tidak akan ditindaklanjuti             |

Ketika skill menyebut role (misal "apply the AFK-ready triage label"), gunakan string label yang sesuai dari tabel ini.

Edit kolom kanan sesuai vocabulary yang kamu gunakan sebenarnya.
